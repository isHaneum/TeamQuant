9. AI가 쓴 것을 "사람이 판단했다"고 적지 않습니다 [추론, S40 제31조·S50].
10. 증권사 제휴 링크, 추천 코드, 협찬, 광고를 넣지 않습니다 [추론, 금소법 제22조① — S8 2021-06-08·S30 2026-04-20 기준].
11. "공식", "금감원 인증"처럼 금융기관으로 오인될 표현을 쓰지 않습니다 [사실, S30 2026-04-20 적발 유형 "금융기관 사칭"].

## 3. 법령·규정 요약

### 3.1 자본시장법(현행 법률 제21647호, 2026-05-12 공포, 2026-11-13 시행) [사실, S51]

- 제6·7·101조는 2026-11-16 이후 바뀌지 않았다고 봅니다(law.go.kr 현행 판이 2026-11-24 기준으로도 제21647호) [추론]. 제7·101조 마지막 개정은 2024-08-14 시행분입니다 [사실, 보도 일치]. 제6조 마지막 개정일(2021-12-21)은 조문 연혁으로 다시 확인해야 합니다 [미확인].
- **투자자문업**(제6조①⑦): 이익을 얻을 목적으로 계속·반복해 투자판단(종목·수량·가격·시기 등)에 관해 자문하는 영업. 투자일임업은 제6조⑧. 금융위는 무료 회원에게 하는 1:1 자문도 영업으로 하면 투자자문업이 될 수 있다고 회신했습니다 [사실, S64].
- **적용 배제**(제7조③): 간행물·통신물·방송 등으로 하는 **개별성 없는 조언**(개별 투자자를 상정하지 않고 다수에게 일방적으로 하는 조언)은 투자자문업으로 보지 않음. 다만 **온라인에서 일정한 대가를 낸 고객과 의견을 주고받을 수 있으면** 그렇지 않음(2024-08-14 시행) [사실, S65 현행 문구].
- **유사투자자문업**(제101조): "고객으로부터 일정한 대가를 받고" 하는 개별성 없는 조언. 조문상 대가가 요건이지만, 금융위는 "영업으로 하거나 일정한 대가를 받고 행하는 경우"라면 신고 대상일 수 있다고 회신했습니다 [사실, S63 2024-08-28]. 광고·후원·홍보 같은 수익 요소가 생기면 다시 검토합니다 ⚖️. 유사투자자문업자는 개별성을 반영한 조언을 할 수 없습니다(대법원 2023다311665, 2024-05-09) [사실, S65 해설].
- **제101조의2·제101조의3**(2024 신설): 유사투자자문업자의 불건전 영업 금지와 광고 준수사항. S30 적발 유형의 근거 조항입니다. 조 제목만 확인했고 원문은 [미확인].
- **2024 양방향 개정**: 대가를 받는 오픈채팅·SNS·답장 가능한 메신저는 투자자문업 등록 대상. 위반 시 미등록 투자자문업자로 3년 이하 징역 또는 1억 원 이하 벌금 [보도 일치, 금융위 원문 미열람, S17 2024-08-13]. 금감원은 2024-07-22 안내에서 유료 영업은 댓글을 막은 단방향 채널에서만 가능하다고 함. 텔레그램을 특정한 문구는 찾지 못함 [미확인, S16 보도].
- **개별성 기준**(대법원 2018도4413, 2022-10-27): "특정"은 인원 수가 아니라 투자목적·재산상황·경험 같은 개별 사정이 반영되는지로 판단. 자동매매 프로그램과 필수 설정값을 함께 주면 투자판단 제공으로 볼 수 있음. 이 사건은 개별성이 없어 무죄 유지 [S11].

- **부정거래**: 미리 산 종목을 이해관계를 숨기고 추천한 뒤 팔면 제178조①1호 위반이고, 같은 행위는 제178조② "위계의 사용"에도 해당합니다. 적용 대상에는 등록 업자가 아닌 "투자 관련 웹사이트 운영자 등"도 들어갑니다(2014도6910, 2017-03-30) [사실, S3]. 2024도11686(2026-01-15)은 제3자(가족 등) 보유를 숨긴 추천도 부정거래가 될 수 있다며 원심을 파기환송했습니다(유죄 확정 아님) [사실·보도, S25].

> "Team Quant는 종목을 골라 주는 서비스가 아니라, 내가 정한 규칙을 지켰는지 확인하는 무료 도구입니다. 돈을 받지 않고, 모두에게 같은 화면을 보여 주고, 1:1 상담을 하지 않기 때문에 자본시장법상 투자자문이나 유사투자자문 신고 대상이 아니라고 판단했습니다. 실제 주문은 개발자 본인 계좌에서, 조항마다 동의를 받은 뒤에만 나갑니다. 남의 계좌를 대신 굴리는 건 투자일임이라 하지 않습니다. 뉴스 검색 결과를 AI로 요약하던 기능은 검색 API 약관이 AI 입력을 막는다는 확인 결과가 나와 바로 멈췄습니다. 방문자 기록은 그 사람 브라우저에만 있고, ※ AI가 쓴 글에는 모두 AI 표시와 원문 링크를 붙였습니다. 유료화나 다른 사람 계좌 연결은 변호사 검토와 등록이 먼저입니다."

### 7.3 쓰지 않을 말과 바꿀 말

| 쓰지 않을 말 | 대신 쓸 말 |
|---|---|
| 수익 보장, 손실 없음 | 과거 결과이며 앞으로를 보장하지 않습니다 |
| 추천 종목, 유망 종목 | 규칙을 통과했는지 확인한 종목(모의계좌 기준) |
| AI가 골라 줌, AI가 예측 | AI가 기사를 요약하고 규칙 관문을 확인함 |
| 자동으로 돈 벌어 줌 | 내가 정한 규칙대로 자동 점검·(본인 계좌) 실행 |
| 목표 수익률 N% | 기간·비교 지수·비용을 밝힌 과거 수익률 |
| 수익률 N% 달성(종목별 합산) | 계좌 전체 기준, 손실 구간 포함 |
| 투자 상담해 드립니다 | 1:1 상담은 하지 않습니다 |
| 공식, 인증 | 수업 과제 · 금융투자업자 아님 |
| 실시간 시세 | 공개 시세(지연 가능) |
| AI라서 책임 없음 | 사람이 하면 안 되는 일은 AI도 하지 않습니다 |

시연 주의: 실계좌 화면·금액·키 화면을 띄우지 않습니다. 토스 자료는 발표 자료로도 배포 금지입니다 [S39]. 시연은 팀 모의계좌·내 가상계좌·공개 시세 화면으로 합니다. 브라우저 저장 위치와 "내 기록 지우기"를 직접 보여 주면 개인정보 설명이 쉽습니다.

### 7.4 예상 질문과 짧은 답

| 질문 | 답 |
|---|---|
| 이거 투자자문 아닌가요? | 투자자문은 개인 사정을 반영해 1:1로 판단을 주는 영업입니다. 저희는 무료로 모두에게 같은 화면을 보여 주고 1:1 답을 하지 않습니다(제7조③, 대법원 2018도4413). 유사투자자문은 조문상 대가가 요건이고 금융위는 영업성도 봅니다. 저희는 대가도 광고도 없어 해당하지 않는다고 봅니다. |
| 남의 계좌 자동매매도 되나요? | 안 합니다. 남의 계좌의 투자판단을 넘겨받아 영업으로 운용하면 투자일임업입니다(금융위 회신 2021-06-01). 등록 없이 하면 처벌될 수 있어, 무료·지인이어도 팀 규칙으로 하지 않고 개발자 본인 계좌에만 씁니다. |
| 개인정보는요? | 회원가입이 없고 서버에 방문자 정보를 저장하지 않습니다. 기록은 각자 브라우저에만 있고 버튼 하나로 지웁니다. 호스팅은 미국 Vercel·GitHub이라 접속 기록은 그 회사 정책을 따릅니다. |
| AI가 틀리면요? | 기사에 있는 이유만 쓰게 하고 이유마다 원문 링크를 답니다. ※ 모든 결과에 "AI · 틀릴 수 있음" 표시가 있고, 잘못된 건 발견 즉시 내리고 정정 기록을 남깁니다. AI 카드는 가상 돈 모의계좌에만 쓰입니다. |
| 수익률 공개는 광고 아닌가요? | 판매하는 상품·대가·구매 링크가 없어 광고로 볼 가능성은 낮습니다. 그래도 금융위가 적발한 유형(목표 수익률, 종목별 합산, 수익 보장)은 쓰지 않고, 기간·비교 지수·비용·손실 구간을 함께 보여 줍니다(금융위 2026-04-20). |
| 뉴스 요약은 저작권 문제 없나요? | 지금은 멈췄습니다. 뉴스 검색 API 개정 약관이 검색 결과를 AI에 넣거나 가공해 노출하는 것을 막는다는 공식 공지 제목과 보도가 일치해서, 2026-11-27에 끄고 기사 없이 숫자만 쓰는 방식으로 바꾸고 있습니다. 시사 사실 자체는 보호 대상이 아니지만(저작권법 제7조) 기사 문장·제목은 보호될 수 있어, 남의 기사를 AI로 요약해 올리는 방식은 쓰지 않습니다. |
| 유료로 하면요? | 유료가 되면 유사투자자문 신고가 필요하고, 답장 가능한 채팅방까지 열면 투자자문업 등록이 필요합니다(2024-08-14 시행). 비공식 시세도 계약 데이터로 바꿔야 합니다. 그 전에 변호사 검토를 받습니다. |
| AI 기본법은 지켰나요? | 2026-01-22 시행된 법은 생성형 AI 사용을 미리 알리고 결과물에 표시하라고 합니다. 수업 과제가 대상인지는 불확실하지만, ※ 해당 여부와 관계없이 고지와 AI 배지를 붙였습니다. 개인을 심사하지 않아 고영향 AI는 아니라고 봅니다. |
| 증권사 API를 이렇게 써도 되나요? | 토스·한국투자증권 약관은 본인 계좌·본인 키만 허용하고 시세 재배포를 막습니다. 그래서 키는 본인 PC에만 두고, 토스 자료는 공개하지 않으며, ※ 팀 모의계좌 공개 자료에서도 종목별 가격을 뺍니다. |
| 팀원이 공개 종목을 미리 사 두면요? | ※ 공개 카드 종목은 팀원이 공표 전후 5거래일 동안 본인·가족·지인 계좌로 사고팔지 않는 규칙을 둡니다. 숨기고 추천 후 팔면 부정거래라는 판례가 있고(대법원 2017-03-30), 가족 계좌 보유를 숨긴 경우도 문제 될 수 있다는 판결이 있습니다(2026-01-15, 파기환송). |

- 새로 확인: Anthropic AUP(2026-11-12 시행), Anthropic 보관·처리 지역, 금융분야 AI 가이드라인(2026-06-22), 금융위 점검 결과(2026-04-20), 텔레그램 방침 갱신(2026-08-21), 마이데이터 발전방안(2026-08-25), 개인정보 AI 특례(2027-03-09 시행), 토스 호출 한도 수치.
- 새로 발견: 하락 매수 카드를 "사람이" 쓴다는 오표기, 내 포트폴리오 판단 열, PC 패키지 링크, 네이버 검색 결과의 AI 입력.
- 바뀌지 않음: 자본시장법 제6·7·101조, 토스 약관 v2, KIS 약관, 저작권법(법률 제21595호).
