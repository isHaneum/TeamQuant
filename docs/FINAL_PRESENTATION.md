# Team Quant 최종 발표 — 서비스 정리

Team 15 · 김동원(팀장·기획) · 조혜민(기획) · 유한음(개발) · 정리 기준일 2026-11-26

> 숫자는 모두 기준일 값이다. 발표 전날 다시 확인해 바꾼다. 실계좌 금액·보유·개인 계획은 이 문서에 넣지 않는다.

## 한 문장

**흔들리지 않는 개인투자자: 나에게 맞는 규칙을 세우고, 쉽게 점검하고, 규칙대로 투자하게 돕는 플랫폼.**

종목을 찍어 주는 서비스가 아니다. 규칙을 정하게 하고, 그 규칙을 지켰는지 매일 보여 주고, 텔레그램으로 쉽게 확인·동의하게 한다. 퀀트 기능은 예측이 아니라 이 과정을 돕는 도구다.

## 1. 문제 — 개인투자자는 왜 흔들리나

- 급락·뉴스·테마에 반응해 규칙 없이 사고판다. 규칙이 있어도 지켰는지 확인하기가 번거로워 잊는다.
- 유행 테마를 쫓는 상품은 평균적으로 나빴다: 특화(테마) ETF는 상장 뒤 5년 동안 위험을 감안한 수익이 약 −30% 뒤졌다(Ben-David 외, *Review of Financial Studies* 2023 · [NBER w28369](https://www.nber.org/papers/w28369)). 2년 동안 시장보다 +100% 넘게 오른 산업은 다음 2년에 −40% 넘게 빠질 확률이 약 53%였다(Greenwood·Shleifer·You 2019 · [NBER w23191](https://www.nber.org/system/files/working_papers/w23191/w23191.pdf)).
- 우리 자체 시험도 같은 결론이었다: 성장·가치 점수로 고른 종목은 표본 밖에서 지수 초과수익을 맞히지 못했고(자체 연구 G2 · 2026-11-12), 200일선 같은 추세 규칙도 사전 등록 시험에서 탈락했다(결정 47 · 2026-11-18).
- **그래서 예측 대신 규칙을 만든다.** 무엇을 살지보다 "얼마나, 언제, 어디까지"를 정하고 지키는 것이 개인이 통제할 수 있는 부분이다.

## 2. 우리의 답 — 규칙 → 점검 → 실행 → 기록

```
  ① 규칙 세우기 ──▶ ② 계좌 연결 ──▶ ③ 매일 점검(홈) ──▶ ④ 텔레그램으로 확인·동의
        ▲                                                         │
        └──── ⑥ 기록으로 고치기 ◀──── ⑤ 규칙대로 주문(자동·지정가) ◀──┘
```

## 3. 사용 흐름 — 과정 풀어내기

| 단계 | 사용자가 하는 일 | 서비스가 하는 일 |
|---|---|---|
| ① 규칙 세우기 | 질문 3개에 답하고(잃어도 되는 정도 등) 한도를 고른다. 종목과 목표 비중을 정한다. PC 프로그램에서는 "한 종목 20% 넘지 않게"처럼 말로 적어도 칸이 채워진다. | 한 종목 상한 · 현금 최소 · 하루 손실 한도 · 30일 매매 횟수 같은 한도를 만든다. 확정하면 28일 동안 잠그고, 계획 변경은 30일에 2번까지만 허용한다 — 흔들릴 때 규칙을 바꾸지 못하게. |
| ② 계좌 연결 | 모의 또는 실계좌를 고른다. | **팀 모의계좌**(한국투자증권 모의투자 1억, 규칙 엔진이 자동 운용 · 공개) · **내 가상계좌**(가입 없이 브라우저에서, 실시간 시세로 가상 체결) · **실계좌**(토스증권, 내 PC 프로그램 · 키는 내 PC에만 암호화 · 기본은 조회만). |
| ③ 매일 점검 | 홈을 연다. | 첫 줄에 "규칙 N개 중 M개 지킴"과 어긴 규칙의 이유. 원금 대비 수익률과 같은 기간 S&P500·코스피 비교. 오늘 시장 한 줄과 내 종목 뉴스·공시. 사기 전에는 '주문 점검'이 한도를 먼저 확인한다. |
| ④ 텔레그램 | 휴대폰으로 알림을 받고 버튼을 누른다. | 오늘 밤 주문 예정, 보낸 주문, 체결 결과를 한 줄씩 알린다. 설정이 바뀌면 휴대폰으로 동의를 묻고, 동의가 없으면 주문하지 않는다. |
| ⑤ 규칙대로 실행 | (자동) | 규칙이 정한 비중과 어긋난 만큼만 주문한다. 지정가로 내고, 안 채워지면 가격을 정해진 한도 안에서만 고쳐 다시 낸다. 매매 전 확인(상한 · 현금 · 하루 손실)을 통과한 것만 보낸다. |
| ⑥ 기록으로 고치기 | 주간 결과를 본다. 직접 고른 종목은 근거·한도·제외 조건·기한을 적는다. | 모든 판단·주문을 고칠 수 없는 기록으로 남기고, 규칙을 지켰는지·지수보다 나았는지를 보여 준다. 규칙 변경은 이유와 함께 남는다. |

## 4. 계좌 — 모의와 실계좌를 같은 규칙으로

- **팀 모의계좌**: 2026-11-09부터 규칙 엔진이 스스로 운용한다. 기준일 원금 1억 원, 같은 기간 수익률 −2.51%로 같은 비중의 지수+현금(−3.70%)보다 1.2%p 덜 빠졌다(11-09~11-26, 17거래일 · 기간이 짧아 운의 영향이 크다). 주문 59건 · 실행 19회 · 의도하지 않은 중복 주문 0건.
- **내 가상계좌**: 누구나 가입 없이 만든다. 장부는 그 사람의 브라우저에만 저장되고, 호가 차이·수수료·세금·환전 비용을 넣어 체결을 흉내 낸다. 장중에는 실시간 시세로, 장 밖이면 다음 장 시가로 체결한다.
- **실계좌(토스)**: 내 PC에서 도는 프로그램으로만 연결한다. 키는 Windows 금고로 암호화해 내 PC에만 둔다. 본인 계좌에 한해 규칙대로 자동 주문을 켤 수 있지만, 조항별 동의(휴대폰 버튼) · 멈춤 파일 · 설정이 바뀌면 다시 동의가 있어야만 주문이 나간다.

## 5. 텔레그램 — 규칙을 쉽게 지키는 통로

- 알림 원칙: 첫 줄에 무슨 일인지, 다음 줄에 한 건씩, 마지막에 할 일. 내부 코드나 영어 상태값을 쓰지 않는다.
- 동의 버튼: 이 PC가 보낸 요청에, 짝을 맺은 본인 계정이 누른 것만 받는다. 요청 뒤 설정이 바뀌면 그 버튼은 무효다.
- 규칙 코치(PC 프로그램 사용자): 흔들릴 때 "지금 다 팔까?"라고 물으면 미리 정한 규칙과 기록으로만 답한다. 종목·시점은 권하지 않고, 계좌 자료는 비율만 쓴다. 알림·동의 봇과 따로 둔다(텔레그램은 봇 하나에 받기를 하나만 허용).
- 예시:
  ```
  ⏸ 토스 계좌 · 비중 맞추기 11/25(수) 23:45 · 주문 안 함
  설정이 바뀌어 다시 동의해야 주문이 나갑니다.
  할 일: 이 대화에 온 동의 요청의 [동의]를 누르면 다음 실행부터 주문이 나갑니다.
  ```

## 6. 퀀트·AI 기능은 '돕는 도구' — 예측하지 않는다

| 기능 | 하는 일 | 쓰는 곳 |
|---|---|---|
| 위험 몫 나누기(위험 예산) | 종목마다 위험을 정한 몫만큼 나누도록 비중을 계산한다(수익 예측 없음). | 목표 비중 |
| 하루 손실 범위 | 지금 보유가 나쁜 날 하루에 잃을 수 있는 크기를 계산해 한도를 넘으면 함께 줄인다. | 오늘 점검 · 주문 |
| 변동성 · 급락 대비 현금 | 출렁임이 크면 비중을 줄이고, 공포지수(VIX)가 오르면 대비 현금을 단계적으로 쓴다. | 자동 운용 |
| 과거로 돌려 보기 | 같은 규칙을 2012년부터 과거 시장에 넣어 '덜 잃는 대신 덜 벌었는지'를 보여 준다. | 규칙 화면 |
| 사전 등록 시험 | 규칙을 바꾸기 전에 기준을 먼저 적고 시험한다. 통과 못 하면 넣지 않는다(예: 추세 규칙 탈락). | 결정 기록 |
| 종목 점검표 | 직접 고른 종목은 성장·가치·제외 조건·중국 경쟁을 숫자로 적고, 조건이 깨지면 뺀다. | 종목 추가 |
| 말로 규칙 세우기(AI) | 적은 글을 규칙 칸 초안으로 옮기고, 규칙 엔진이 숫자를 다시 검사한다. 저장은 원래 확정 단계에서만. | 규칙 화면(PC) |
| 오늘 시장 AI 요약 | 장 마감 기사로 한 줄 결론과 이유 3개를 쓰고, 이유마다 기사 링크를 단다. 지어내지 않고 인과를 단정하지 않는다. | 홈 |
| 종목 점검(AI) | 웹 검색으로 조사 → 출처를 가린 재검증 → 반대면 보류. 이번에 실제로 본 주소만 근거로 쓴다. | 팀 모의계좌 |

## 7. 안전과 신뢰

- 무료 · 투자 권유 아님 · 남의 계좌를 대신 운용하지 않음(투자자문·투자일임 밖에 머무는 설계).
- 동의는 행동하는 순간에, 조항마다 따로 받고 기록은 바꿀 수 없게 남긴다. 미리 체크된 칸이 없다.
- 키·실계좌 정보는 내 PC에만 암호화. 공개 자료에는 계좌번호·주문번호를 넣지 않는다.
- 자동 테스트 491개(웹) · PC 사본 597개, 외부 모델 교차 검증과 보안 점검을 거쳤다(결정 63·64).
- AI 기능은 개인 API 키로 PC 프로그램에서만 돈다. 키는 PC 금고에만 두고, 공개 사이트에는 API를 부르는 창구가 없다. 월 사용 상한을 코드로 막는다(결정 69).

## 8. 시연 순서(약 5분)

1. 홈 첫 줄 — "규칙 6개 중 4개 지킴"과 어긴 규칙의 이유, 지수와 비교.
2. 규칙 화면 — 질문 3개 → 한도 → 종목·비중 → 확정(28일 잠금). PC에서는 '말로 적기'로 문장을 적으면 칸이 채워지고, 확정은 원래대로.
3. 모의투자 — [내 가상계좌 | 팀 모의계좌] 탭, 가상계좌 만들기(동의 → 첫 점검).
4. 텔레그램 — 오늘 밤 주문 · 동의 버튼 · 체결 결과 알림 화면. 코치에 "지금 다 팔까?"를 물으면 규칙으로 답하는 장면.
5. 기록 — 직접 고른 종목(근거 · 한도 · 제외 조건 · 기한)과 결정 기록.

## 9. 한계와 다음 단계

- 모바일 화면 실측과 정리, 정식 개인정보 처리방침.
- 여러 사용자가 각자 텔레그램을 쓰려면 서버 쪽 봇과 처리방침이 필요하다(지금은 PC 프로그램 사용자만).
- 모의 운용 기간이 짧다 — 성과는 최소 3~6개월을 두고 평가한다.
- 실계좌 원금은 아직 추정이다(기록 시작일부터). 증권사 입출금 내역으로 실제 원금을 맞추는 것이 다음 일이다.
- AI 기능을 공개 사이트 사용자에게 열려면 서버 쪽 키 관리와 사용자별 사용량 제한이 필요하다.
