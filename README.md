# Team Quant 투자전략 검증 및 모의투자

자연어 투자 원칙을 실행 규칙으로 변환하고, 사용자가 승인한 전략 버전으로 과거 데이터 검증과 모의투자를 수행하는 수업용 웹 프로토타입이다.

## 실행

```powershell
npm run dev
```

`http://127.0.0.1:8766`에서 실행된다. `체험 계정`을 누르면 별도 설정 없이 전체 흐름을 확인할 수 있다.

## 구현 기능

- 사용자별 체험 로그인과 브라우저별 데이터 분리
- 한국어 자연어에서 이동평균·RSI·돌파·손절·익절·비중 추출
- 원문과 변환된 실행 규칙 비교 및 사용자 승인
- 동일 조건에 고정된 전략 버전 ID 부여
- 실제 지연 일봉 데이터 백테스트와 평가 구간 분리
- 수익률, 최대 낙폭, 거래비용, 판단 근거 기록
- 사용자별 모의 현금·보유 종목·평균단가·평가손익
- 전략 판단 따르기 또는 다른 행동과 이유 기록
- 전략 준수율과 판단 증거 CSV 저장
- KIS 국내주식 잔고 읽기 전용 서버 어댑터

## 한국투자 Open API 연결

`.env.example`의 항목을 로컬 환경변수 또는 Vercel Secret으로 설정한다. 키와 계좌번호는 브라우저 코드에 넣지 않는다.

```text
KIS_MODE=vps
KIS_APP_KEY=...
KIS_APP_SECRET=...
KIS_ACCOUNT_NO=계좌번호앞8자리
KIS_ACCOUNT_PRODUCT_CODE=01
```

`KIS_MODE=vps`는 모의투자, `prod`는 실전계좌 읽기 전용이다. 현재 구현에는 KIS 실제 주문 API가 없다.

## Vercel 배포

프로젝트 루트를 이 폴더로 지정한다. 별도 빌드 명령과 출력 디렉터리는 필요하지 않다.

1. Git 저장소에 이 폴더를 올린다.
2. Vercel에서 저장소를 Import한다.
3. Root Directory를 `team_quant/market-simulator`로 지정한다.
4. KIS 연결이 필요하면 위 환경변수를 Secret으로 등록한다.
5. 배포 후 `/api/market`과 `/api/kis-account`를 확인한다.

현재 사용자 로그인과 모의 자산은 브라우저 저장소를 사용하는 프로토타입이다. 실제 다중 사용자 서비스에서는 인증 DB와 사용자별 암호화 자격증명 저장소로 교체해야 한다.
